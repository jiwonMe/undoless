Undoless Sans / Undoless Serif — version 0.109, package 0.1.9

Derived from Hakgyoansim Bareondotum R/B and Hakgyoansim Bareonbatang R/B.
Original copyright: Copyright © KERIS. All rights reserved.
Original design: YoonDesign Inc.

The 0.103 base fills 8,822 previously empty Hangul syllables with outline
parts from the same native style. The 0.104 stage scales all glyphs and
horizontal metrics to 95%. The 0.105 symbol stage adapts spacing and ink
frames using Pretendard 1.3.9; all outlines remain native.

Version 0.109 restores the width-95 base, then scales only Hangul syllable
and compatibility-jamo ink to 97% in both axes. X is centered in the existing
advance cell and Y scales about the baseline. Hangul advances are rounded
to 97%, with ink centered in the smaller cell. Latin, numerals, symbols,
non-Hangul advances, kerning and line metrics remain unchanged. The temporary Sans-90%
stage is superseded. Desktop names now match Undoless Sans / Undoless Serif.
See analysis/hangul-spacing97/ for exact transforms, scope and current checks.
Additional Hangul syllables remain algorithmic drafts needing visual review.
